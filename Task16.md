# Первый пример

После изменения сигнатуры метода в родительском классе в дочернем классе будут доступны 2 метода: `makeGenericSound` из родительского класса и `makeSound` из дочернего класса.

# Второй пример

Метод `makeSound(int numberOfSounds)` не переопределённый, а перегруженный. Из-за этого строка `cat.makeSound(3);` ошибочна, код не скомпилируется.

# Третий пример

Может быть из-за того, что тип значения - `Object`, то метод `toString()` будет возвращать имя класса + hashCode.
